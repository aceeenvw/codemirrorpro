# ⊹ Code Mirror Pro ⊹

Tap **Expand** beside a SillyTavern text field to edit prompts, greetings, Markdown, or code. Changes sync to the original field as you type.

## Features

- **Find and replace:** Press **Ctrl/Cmd+F** to jump between matches or replace them. Search by whole word, match case, or use regular expressions.
- **Writing tools:** Format selected text, get suggestions as you type `{{` in macro-enabled fields, and count tokens with SillyTavern’s current tokenizer.
- **Code editing:** Highlight CSS, JavaScript, JSON, HTML, and Markdown. Switch between code and prose profiles for folding, line numbers, or word wrap.
- **Desktop and mobile:** Choose a theme and font size, swipe the toolbar on small screens, or edit in fullscreen. Controls are available in English and Russian.
- **With Pocket Tweaks:** Choose a result in **Find in greetings** to open the expanded editor with the matching passage selected.

## Install

In SillyTavern, open **Extensions → Install extension**, paste `https://github.com/aceeenvw/codemirrorpro`, then reload. If you use the original Extension-CodeMirror, disable it so only one extension handles expanded fields.
